## ✨ **المميزات الرئيسية**

### 📋 **إدارة المهام**
- إضافة مهام (مجانية / بريميوم / متكررة)
- تحديد المهام المنجزة
- فلترة المهام (الكل / قيد التنفيذ / منجزة / بريميوم)
- ذكاء اصطناعي لتوليد المهام

### 💰 **إدارة المصاريف**
- إضافة مصاريف مع إمكانية رفع صور
- تصنيف المصاريف (طعام - مواصلات - فواتير - إيجار - صحة - تعليم)
- عرض إجمالي المصاريف (اليومي / الشهري / الإجمالي)
- فلترة المصاريف حسب النوع والحالة

### 💳 **إدارة المديونيات**
- تسجيل مديونيات مع مواعيد الاستحقاق
- سداد أقساط المديونيات
- متابعة المدفوع والمتبقي
- تنبيه المديونيات المتأخرة

### 🧾 **إدارة الضرائب**
- تسجيل ضرائب القيمة المضافة
- حساب ضريبة الدخل
- سداد الضرائب
- تقارير ضريبية مفصلة

### 📊 **الميزانية الذكية**
- توزيع الميزانية تلقائياً حسب الراتب
- نصائح ذكية للادخار
- توليد ميزانية باستخدام الذكاء الاصطناعي

### 📈 **المحاسبة المتكاملة**
- ميزان المراجعة (Trial Balance)
- قائمة الدخل (Income Statement)
- الميزانية العمومية (Balance Sheet)
- نظام تدفق السلفة

### 🛡️ **لوحة تحكم المدير**
- مراقبة المستخدمين
- خريطة توزيع المستخدمين
- سجل النشاطات
- إدارة صلاحيات البريميوم

### ☁️ **المزامنة السحابية**
- مزامنة البيانات بين الأجهزة (موبايل + كمبيوتر)
- يعمل مع Firebase Realtime Database
- وضع غير متصل (Offline Mode)
